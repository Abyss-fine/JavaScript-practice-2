## 6. Реализация модели задач

Для работы программы используется объект задачи следующей структуры:

```javascript
{
  id: 20,
  title: "Подготовить демонстрацию",
  completed: false,
  priority: "medium"
}
```

Правила модели:

- `id` — положительное безопасное целое число; идентификаторы внутри списка должны быть уникальными.
- `title` — строка длиной от 1 до 100 символов после удаления пробелов по краям.
- `completed` — логическое значение. Для новой задачи устанавливается `false`.
- `priority` — одно из значений `low`, `medium` или `high`. По умолчанию используется `medium`.

Для проверки данных применяется функция `createTask()`. При успешном создании она возвращает объект с полями `ok: true` и `task`. При ошибке возвращается `ok: false` и текст причины.

## 7. Реализованные функции

В файле `src/task-service.js` реализованы следующие функции:

| Функция | Назначение |
|---|---|
| `createTask()` | Проверяет данные и создаёт новую задачу. |
| `findTaskById()` | Находит задачу по идентификатору с помощью `find()`. |
| `getPendingTasks()` | Возвращает невыполненные задачи с помощью `filter()`. |
| `getTaskTitles()` | Формирует массив названий задач с помощью `map()`. |
| `getTaskStats()` | Рассчитывает общее количество задач, количество выполненных и оставшихся задач, а также процент выполнения. |
| `addTask()` | Добавляет новую задачу с проверкой корректности данных и уникальности ID. |
| `setTaskCompleted()` | Изменяет статус выполнения задачи. |
| `renameTask()` | Изменяет название задачи. |
| `removeTask()` | Удаляет задачу по идентификатору. |
| `searchTasksByTitle()` | Дополнительная функция для поиска задач по фрагменту названия. |

Функции изменения данных формируют обновлённые массивы, не изменяя исходный массив. Для копирования и обновления объектов применяется поверхностное копирование.

### Особенности дополнительной функции поиска

Функция `searchTasksByTitle(tasks, query)` выполняет поиск по части названия без учёта регистра. Пробелы в начале и конце запроса удаляются. При отсутствии совпадений возвращается пустой массив. При пустом запросе возвращается новый массив со всеми задачами.
