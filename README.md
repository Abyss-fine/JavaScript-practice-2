## 1. Цель работы

Изучить функции JavaScript, работу с массивами и объектами, методы map, filter, find, а также принципы создания новых массивов и объектов без изменения исходных данных.

## 2. Структура проекта

- `src/data.js` — исходные данные и индивидуальный набор задач.
- `src/task-service.js` — функции для работы с задачами.
- `src/main.js` — основной сценарий выполнения программы.
- `examples/functions-and-references.js` — эксперименты с функциями, ссылками и копированием.
- `checks.js` — автоматические проверки функций.
- `package.json` — настройки запуска проекта.

## 3. Запуск программы

Для запуска экспериментов использована команда `npm.cmd run examples`.

Для запуска основного сценария использована команда `npm.cmd start`.

Для выполнения автоматических проверок использована команда `npm.cmd run check`.

Автоматические проверки завершились успешно.
